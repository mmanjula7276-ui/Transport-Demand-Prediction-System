# 🚍 Transport Demand Prediction System

## 📌 Project Overview
The Transport Demand Prediction System is a full-stack web application designed to help users analyze and predict transportation demand. It provides route visualization, location tracking, and demand estimation to support better transportation planning.

## ✨ Features
- User Authentication
- Route Visualization
- Location Tracking
- Demand Prediction
- Interactive Map
- Responsive User Interface

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript
- Leaflet.js

### Backend
- Node.js
- Express.js
- Socket.io

### Database
- MongoDB

```
client/
server/
```

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/mmanjula7276-ui/Transport-Demand-Prediction-System.git
```

### Install dependencies

```bash
cd client
npm install

cd ../server
npm install
```

### Run the project

Frontend

```bash
npm run dev
```

Backend

```bash
npm start
```
